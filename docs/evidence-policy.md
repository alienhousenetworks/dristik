# Dristik 2.0 Evidence Policy

## Core Principle: No Speculation
Every finding generated by Dristik agents MUST be backed by deterministic evidence. Agents may reason over evidence, but cannot fabricate observations.

## Provenance States
1. **RAW_TELEMETRY**: Unmodified HTTP response codes, headers, and timings.
2. **RENDERED_DOM**: Playwright-inspected client DOM tree with computed styles.
3. **EXTRACTED_CONTENT**: Parsed textual, heading, metadata, or schema structures.
4. **THIRD_PARTY_OBSERVATION**: Verified API data from Search Console, PageSpeed, or CrUX.
5. **SYNTHESIZED_INFERENCE**: Cross-domain LLM reasoning with confidence scoring.

## Immutability & Ledger
All snapshots and raw responses are hashed (SHA-256) and cataloged in the Evidence Store before any analytical agent begins execution.
